# Urban Traffic Flow Simulation and Optimization using AnyLogic

## Overview

This project investigates traffic flow optimization for a real-world urban intersection in Magdeburg, Germany. Using AnyLogic simulation software, a validated traffic model was developed to analyze current traffic conditions and evaluate potential infrastructure improvements.

The project combined statistical data analysis, simulation modeling, validation techniques, and scenario testing to support evidence-based decision making for urban traffic planning.

## Objectives

* Model real traffic behavior at a multi-road intersection.
* Collect and analyze traffic flow data.
* Fit probability distributions for vehicle arrivals.
* Validate simulation outputs against observed traffic conditions.
* Evaluate alternative infrastructure designs.
* Recommend improvements based on quantitative performance metrics.

## Methodology

### Data Collection

Traffic surveys were conducted to determine:

* Vehicle inter-arrival times
* Turning probabilities
* Traffic throughput
* Road usage patterns

### Statistical Analysis

The collected data was analyzed using:

* Histograms
* Q-Q Plots
* Exponential Distribution Fitting
* Chi-Square Goodness-of-Fit Tests

### Simulation Development

A traffic simulation model was developed in AnyLogic using:

* Road Traffic Library
* Process Modeling Library
* Agent-Based Components

The model represented:

* Vehicle generation
* Traffic movement
* Road priorities
* Turning behavior
* Queue formation

### Validation

Model reliability was assessed using:

* Sensitivity Analysis
* Input-Output Validation
* Confidence Interval Analysis
* Replication Experiments

## Experiments

Four traffic optimization scenarios were evaluated:

1. Single Large Roundabout
2. Two Smaller Roundabouts
3. Pedestrian Traffic Lights
4. Removal of One-Way Street Restriction

## Results

Performance metrics included:

* Throughput
* Average Travel Time
* Traffic Flow Efficiency

The analysis showed that the current intersection configuration remained the most effective solution under both existing and increased traffic volumes.
